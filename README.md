# Collar Health Shiny App

MoveApps

Github repository: *github.com/sitkensis22/Collar-Health-Shiny-App* (*https://github.com/sitkensis22/Collar-Health-Shiny-App*)

## Description
Provides visualization tools for alerts generated by Collar-Health-Alert-App (and possibly filtered by Collar-Health-Filter-App) including Leaflet map, individual and all tabular data, and alert-specific plots. The user can (1) select data to view by individual and filter by those with or without alerts; (2) select alert events; (3) select one of 6 basemaps; (4) filter data by date or number of locations; (5) remove individuals from the dataset; (6) link to the individual's Movebank deployment page; (7) download individual data, all data, or a an individual report that contains summary, map, and location data; (8) and select which data fields to display in individual data table.  

## Documentation
This App creates a Shiny UI that allows the interactive visualization of move2 location data in map, graphical, and tabular form. The App is meant to work in conjunction in a workflow with the Collar-Health-Alert-App (and possibly filtered by Collar-Health-Filter-App) and uses the move2 dataset with fields appended for each alert type: `mortality`, `cluster`, `nsd`, `voltage`, `gps_accuracy`, `gps_transmission`, and `gps_resurrection`, and the number of unique alerts per individual, `nAlerts`. The App will not work without these fields appended to the dataset. The alerts are binary fields (0/1) indicating which locations meet the one of 7 alert criteria, and these locations are displayed in orange color on the Leaflet map. The start and end of the movement track are colored green and red, respectively, on the Leaflet map. The user can select individuals by clicking on the "Track information" table, the "All data" table, or in the "Select individual" dropdown menu. The "Select alert" dropdown menu will automatically update as different individuals are selected, as will the date range, number of locations, "Individual data" table, and Event plots. The Leaflet map locations will show the datetime when the user hovers over the points, and tooltips will also be displayed on the Event plots as the user hovers over the points. Note that the "device_id" field is the `tag_local_identifier` (or `serial_no`) field in the track data.

### Settings 
**Alert toggle (`alert_toggle`):** This switch filters the individuals in the data based on if they have any alerts or not. Defaults to selecting all data. 

**Select individual (`individual_select`):** Select the individual based on the track id column in the move2 dataset. Note that the individual can also be selected by clicking on "Track information" or "All data" table rows. Defaults to the first id in the move2 dataset.

**Select alert (`notification_type`):** Select the alert to display in the Leaflet map, "Individual data" table, and Event plot tabs. Note that this dropdown menu will automatically update based on the selected individual. Possible values are: mortality, cluster, nsd, voltage, gps_accuracy, gps_transmission, and gps_resurrection.

**Select basemap (`basemap_type`):** Select provider basemap for Leaflet map tab. Options include: World Imagery, World Topo Map, World Street Map, NatGeo World Map, OpenStreet Map, and OpenStreet Topo Map. Default is World Imagery.

**Data filter toggle (`data_toggle`):** This switch filters the individual's data by either a date range or number of locations. Depending on the position of the toggle, a conditional panel will appear for either the date range or number of location data filters. Default is to filter by date range. 

**Date range filter (`date_range`):** Select the date range to filter the move2 dataset by. Note that the available date range will automatically update when different individuals are selected. Default is the entire available date range.

**Number of locations filter (`number_locations`):** Select the number of locations to filter the move2 dataset by. Note that the maximum number of locations will automatically update when different individuals are selected. Default is the maximum number of locations.

**Remove individual (`delete`):** This button will remove the currently selected individual from the dataset. This feature was provided for data editing purposes where an individual's deployment was ended on Movebank and the user does not want to consider this indvidual for further inspection.

**Open Movebank (`movebank_link`):** This button will open a new webpage tab of the currenly selected individual's deployment page on Movebank. Note that the user must be logged into Movebank for this page to appear properly, which is recommended before the App is run and data editing commences. 



**Store UI settings (`Store settings`):** Click to store the current settings of the App for future Workflow runs.
